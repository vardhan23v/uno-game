## 🌟 Overview

**UNO Game** is a web-based implementation of the classic card game. It features a complete game engine written from scratch in vanilla JavaScript, managing complex game states including card drawing, color matching, special action cards (Skip, Reverse, Draw Two, Wild, Wild Draw Four), and a robust AI opponent.

## ✨ Key Features

- **Classic UNO Rules:** Full implementation of standard UNO mechanics including color matching, number matching, and action cards.
- **Smart AI Opponent:** A JavaScript-powered computer player that knows when to play action cards, change colors, and draw from the deck.
- **Responsive Design:** Clean, CSS-driven UI that scales gracefully across different screen sizes.
- **Dynamic Card Rendering:** Cards are generated dynamically via the DOM with realistic styling and colors.
- **Zero Dependencies:** Built entirely with raw web technologies—no frameworks, libraries, or external dependencies.

## 🛠️ Technology Stack

- **Frontend Structure:** HTML5
- **Styling:** Vanilla CSS3 (Custom variables, Flexbox/Grid layouts, animations)
- **Game Logic:** Vanilla ES6 JavaScript

## 🚦 Getting Started

Since this project uses only standard web technologies, there is no build step required.

### Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vardhan23v/uno-game.git
   cd uno-game
   ```

2. **Open the game:**
   Simply double-click the `index.html` file to open it in your default web browser, or use a local development server like Live Server (VS Code extension) for hot-reloading:
   ```bash
   npx serve .
   ```
